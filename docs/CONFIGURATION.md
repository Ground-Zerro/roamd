# Справочник конфигурации

> Документация для версии **roamd 1.0.1-r25** (веб-интерфейс **luci-app-roamd 1.0.1-r7**).

Все настройки `roamd` хранятся в `/etc/config/roamd`. После ручной правки примените их:

```sh
uci commit roamd
/etc/init.d/roamd reload
```

`reload` перечитывает конфигурацию без перезапуска процесса и без разрыва соединений. На
контроллере Mesh Wi-Fi-системы изменение `roamd` и `wireless` раскатывается на узлы
автоматически (см. [MESH.md](MESH.md)).

Отсутствующая опция принимает значение по умолчанию. LuCI не хранит значения, равные
умолчанию, поэтому действующий набор удобнее смотреть так:

```sh
ubus call roamd config
```

Логические опции принимают `1`, `true`, `yes`, `on` как «включено», остальное — «выключено».

## Секция `roamd 'global'` — механизмы роуминга

| Опция | По умолчанию | Смысл |
|---|---|---|
| `enabled` | `1` | Главный выключатель. При `0` демон завершается сразу после запуска |
| `ssid` | пусто | Управлять только точками с этим SSID; пусто — всеми |
| `band_steering` | `1` | Активное управление диапазоном: отказы в непредпочитаемом диапазоне и перевод |
| `prefer_band` | `5` | Предпочитаемый диапазон: `5` (или `high`), `2.4` (`2`, `low`); другое значение отключает предпочтение |
| `fast_transition` | `1` | 802.11r для сетей WPA2/WPA3 |
| `ft_over_ds` | `1` | 802.11r через распределительную систему |
| `mobility_domain` | пусто | Четыре hex-цифры; пусто — вычислить из SSID |
| `neighbor_reports` | `1` | 802.11k: Neighbor Report и Beacon Report |
| `bss_transition` | `1` | 802.11v: запросы на переход |
| `apply_wireless` | `1` | Прописывать параметры 802.11k/v/r в `/etc/config/wireless` автоматически |

## Секция `policy 'policy'` — пороги и тайминги

Уровни — в дБм, разницы — в дБ, времена — в миллисекундах.

| Опция | По умолчанию | Смысл |
|---|---|---|
| `rssi_good` | `-55` | Хороший сигнал в предпочитаемом диапазоне: выше — клиента уводят туда |
| `rssi_low` | `-75` | Слабый сигнал: ниже — в предпочитаемый диапазон не уводят, а в нём самом клиент становится кандидатом на уход |
| `rssi_diff` | `30` | Гистерезис: клиента не трогают, если текущий диапазон сильнее целевого на эту величину |
| `cross_band_delta` | `8` | Оценочная разница затухания 2,4 и 5 ГГц для клиентов без измерений |
| `kick_rssi` | `-82` | Ниже этого уровня клиента уводят с диапазона в любом случае |
| `deny_probe` | `1` | Не отвечать клиенту в непредпочитаемом диапазоне; `0` — только запросы 802.11v |
| `allow_kick` | `0` | Отключать клиентов без 802.11v, которых нужно перевести |
| `hold_time` | `30000` | Сколько клиента не трогают после подключения |
| `steer_retries` | `3` | Запросов на переход за одно подключение (с паузой не меньше 5 с) |
| `deny_time` | `15000` | Сколько подряд отказывать клиенту, прежде чем сдаться; срок запрета возврата после принудительного отключения |
| `check_time_high` | `4000` | Срок годности наблюдения клиента в 5 ГГц |
| `check_time_low` | `8000` | Срок годности наблюдения клиента в 2,4 ГГц |
| `age_time` | `90000` | Сколько помнить клиента; на столько же клиент пропускается после «сдаться» |
| `poll_interval` | `2000` | Период опроса hostapd |
| `beacon_req_interval` | `20000` | Минимальный интервал между Beacon Request одному клиенту |
| `log_level` | `1` | `0` — ошибки, `1` — обычный, `2` — отладочный |

Демон исправляет несовместимые значения при загрузке:

| Условие | Исправление |
|---|---|
| `rssi_good` не выше `rssi_low` | `rssi_good = rssi_low + 10` |
| `rssi_diff` меньше 1 | `1` |
| `poll_interval` меньше 500 | `500` |
| `age_time` меньше `hold_time` | `age_time = hold_time × 3` |
| `steer_retries` равен 0 | `1` |

## Секции `device` — правила для клиентов

По одной анонимной секции на клиента.

| Опция | Смысл |
|---|---|
| `mac` | MAC-адрес клиента в нижнем регистре |
| `band` | Разрешённый диапазон: `2.4` (`2`, `low`) или `5` (`high`); нет опции — оба |
| `node` | uci-**list** разрешённых устройств Mesh Wi-Fi-системы: `controller` или `member_id` узла; нет опции — все |
| `alias` | Имя клиента для интерфейса; на поведение не влияет и на узлы не раскатывается |

Секция без `band` и `node` на политику не влияет.

```sh
d=$(uci add roamd device)
uci set roamd.$d.mac='aa:bb:cc:dd:ee:ff'
uci set roamd.$d.band='2.4'
uci add_list roamd.$d.node='controller'
uci add_list roamd.$d.node='a1b2c3'
uci commit roamd
/etc/init.d/roamd reload
```

То же делает метод `mesh_client_update` и карточка клиента в LuCI.

## Секция `mesh 'mesh'` — Mesh Wi-Fi-система

### Общие

| Опция | По умолчанию | Смысл |
|---|---|---|
| `enabled` | `1` | Включить mesh-часть демона; при `0` устройство работает как одиночный роутер без MESH |
| `role` | `controller` | `controller` или `node`. Узлом устройство делает захват; менять вручную не нужно |

### Контроллер

| Опция | По умолчанию | Смысл |
|---|---|---|
| `controller_id` | генерируется | 16 hex-символов; создаётся при первом старте контроллера |
| `controller_name` | пусто | Имя контроллера для отображения |
| `backhaul_enabled` | `1` | Вещать беспроводную транспортную сеть, когда в системе есть узлы |
| `backhaul_ssid` | генерируется | Имя транспортной сети, по умолчанию `Service-Mesh-<id>` |
| `backhaul_key` | генерируется | Ключ транспортной сети |
| `backhaul_delta` | `20` | На сколько дБ сигнал 5 ГГц может уступать 2,4 ГГц при выборе диапазона звена узла |
| `backhaul_min_signal` | `-78` | Нижняя граница рабочего звена узла: более слабое звено используется, только если сильнее ничего не слышно; слабее этого уровня 5 ГГц уступает 2,4 ГГц |
| `wifi_shutdown` | `0` | Гасить точки доступа узла, пока у него нет пути к контроллеру |
| `ft_key` | генерируется | 64 hex-символа: общий ключ обмена ключами 802.11r между точками в сетях WPA3 и WPA-Enterprise |
| `pkg_url` | пусто | Репозиторий пакетов для узлов и самообновления; пусто — репозиторий проекта. Только `https://`; `%b` — ветка, `%a` — архитектура, без подстановок — `<url>/<ветка>/<арх>`. Для своего репозитория его сертификат кладётся в `/etc/roamd/pkg.crt` |
| `auto_update` | `0` | Автоматическое обновление контроллера и узлов |
| `auto_update_every` | `1` | Период проверки: число |
| `auto_update_unit` | `day` | Период проверки: `hour` (до 23), `day` (до 31), `week` (до 5), `month` (до 12) |
| `auto_update_last` | — | Unix-время последней проверки; пишет автообновление |
| `auto_update_result` | — | Итог последней проверки: `updated`, `none`, `error` |

### Узел

Пишутся при захвате и из профиля контроллера; в LuCI узла доступны только для чтения.

| Опция | Смысл |
|---|---|
| `controller_id` | Идентификатор контроллера, чей профиль принимается |
| `controller_name` | Имя контроллера для баннера |
| `controller_addr` | Адрес контроллера; он же DNS-forwarder узла |
| `member_id` | Идентификатор узла — последние 6 hex-цифр MAC |
| `backhaul_parents` | Транспортные точки системы для выбора родителя: записи `<bssid>/<глубина>/<цепочка>/<диапазон>` через пробел |

Узел также получает из профиля `backhaul_*`, `wifi_shutdown` и `ft_key`.

## Секции `member` — узлы (только контроллер)

По одной на узел; создаются захватом.

| Опция | Смысл |
|---|---|
| `id` | `member_id` узла |
| `name` | Имя для отображения; по умолчанию — hostname устройства, у заводского `OpenWrt` — модель, при совпадении с именем другого узла дополняется `member_id`. Повторный захват имя не затирает |
| `hostname` | Системное имя устройства |
| `mac` | MAC аплинка узла |
| `addr` | Адрес узла, закреплённый за ним при захвате |
| `managed` | `1` — узел получает профиль; `0` — только опрашивается |

Секреты в UCI не хранятся: сертификат узла — в `/etc/roamd/members/<id>.crt`, токен входа —
в `/etc/roamd/tokens/<id>` с правами `0600`.

## Что пишется в чужие конфигурации

| Файл | Кто и что пишет |
|---|---|
| `/etc/config/wireless` | автонастройка: опции 802.11k/v/r точек доступа; контроллер и узлы: транспортные точки `mesh_bh_<радио>`; узел: станция `mesh_bh_sta` с BSSID родителя, SSID/шифрование/ключ из профиля, `disabled` при `wifi_shutdown` |
| `/etc/config/network` | контроллер с узлами: `stp=1` и `priority=4096` на мостах; узел при захвате: мост с `stp=1`, статический `lan` с закреплённым адресом, шлюзом и DNS контроллера, удаление `wan`/`wan6` |
| `/etc/config/dhcp` | контроллер: резерв адреса узла `roamd_<member_id>` (`host`); узел: выключенный DHCP-сервер, forwarder на контроллер |
| `/etc/config/firewall` | узел при захвате: удаление зоны `wan` и `forwarding` |
| `/etc/config/system` | узел: `timezone`, `zonename` из профиля |
| `/etc/config/uhttpd`, `/etc/config/rpcd`, `/etc/config/dropbear` | узел при захвате: сертификат, вход `mesh-<id>`, запрет парольного SSH |
| `/etc/shadow` | узел: хеш пароля `root` из профиля |
