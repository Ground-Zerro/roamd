# Документация roamd

> Документация для версии **roamd 1.2.0-r1** (веб-интерфейс **luci-app-roamd 1.2.0-r1**).
> Описывает архитектуру и принципы работы этой версии; в следующих выпусках детали могут
> отличаться.
>
> Проект передан [freenetic](https://github.com/unisequence/freenetic) — дальнейшее
> развитие идёт в его рамках.

`roamd` — демон бесшовного роуминга Wi-Fi для OpenWrt. На одном роутере он управляет
переходами клиентов между диапазонами 2,4 и 5 ГГц средствами 802.11k/v/r. На нескольких
устройствах тот же демон объединяет их в Mesh Wi-Fi-систему: контроллер захватывает узлы,
держит на них единые настройки и помогает клиентам переходить между узлами.

## Состав репозитория

| Путь | Что там |
|---|---|
| `package/roamd/src/` | Демон на C |
| `package/roamd/files/` | Init-скрипт, конфигурация по умолчанию, ACL канала управления |
| `package/luci-app-roamd/` | Страницы LuCI «Роуминг Wi-Fi» и «MESH», русский перевод |
| `build.sh`, `targets/` | Сборка пакетов под матрицу веток и архитектур |
| `repo.sh`, `.github/workflows/release.yml` | Индексы репозитория, подпись, публикация релизов |
| `install.sh` | Установка на роутер из репозитория проекта |
| `keys/` | Публичные ключи подписи репозитория |
